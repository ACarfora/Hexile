# Hexile
Numeric logic game, alternative to sudoku.
Hosted behind a password protected page - hexile.themantraproject.com

## Stack
**Front End**
- SvelteKit
- TypeScript
- Tailwind

## Hosting/Auth
- Cloudflare Pages
- Cloudflare Access

## Styling
